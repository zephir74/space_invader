# Description

This is a custom Space Invaders initially made for Linux systems, but it works also on Windows. For now, it only has 1 alien, but updates are coming

# Requirements

- python3 or higher
- pygame (`sudo apt install python3-pygame`)
- tkinter (`sudo apt install python3-tk`)

# How to use

Simply start the `main.py`, and you should have a launcher for the game

## Controls

- Left/right : arrows
- Shoot : space bar
