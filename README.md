# Description

This is a custom Space Invaders initially made for Linux and Windows systems. It has 2 aliens and custom death screens (depends on the reason of the mission failure)

# Requirements

- python3 or higher
- pygame (`sudo apt install python3-pygame`)
- tkinter (`sudo apt install python3-tk`)

# How to use

Simply start the `main.py`, and you should have a launcher for the game

## Controls

- Left/right : arrows
- Shoot : space bar
